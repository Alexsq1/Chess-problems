# Chess-problems
Two typical algorithmical problems related to chess (in Spanish)

## Includes:
- nDamas: problem of n queens, instantiated to n = 8. Solved with backtracking.
- AjedrezHamiltoniano: hamiltonian path of a knight in an 8x8 chessboard.

## How to use:
- $ java nDamas/Main.java
- $ java AjedrezHamiltoniano/Main.java
